Option A (website, no commands):
 1. github.com -> New repository -> name: networkwalks-w2-footprinting-network-scanning
 2. Click "uploading an existing file", drag in everything INSIDE this folder
    (README.md, LICENSE, .gitignore, report/, evidence/), then Commit.

Option B (command line):
 cd networkwalks-w2-footprinting-network-scanning
 git init && git add . && git commit -m "Add W2 footprinting & network scanning report"
 git branch -M main
 git remote add origin https://github.com/<your-username>/networkwalks-w2-footprinting-network-scanning.git
 git push -u origin main
